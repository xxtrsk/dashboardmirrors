# 🚀 Пошаговая инструкция: Подключение Telegram-бота к Google Sheets и Дашборду (Вариант Б)

Эта связка работает **100% бесплатно**, круглосуточно 24/7 и **не требует никаких выделенных серверов или VPS**. Всё функционирует на базе облачной инфраструктуры Google Apps Script.

---

### Архитектура решения:
```
📱 Смартфон Овнера / Тимлидов (Telegram)
         │
         │ (команды /out, /in, /balance, /split)
         ▼
🤖 Telegram Webhook ➔ 📄 Google Apps Script
                               │
                               ▼
                    📊 Google Таблица ("Транзакции")
                               ▲
                               │ (REST API doGet / doPost)
                               ▼
                    🌐 Vercel Дашборд (MIRRORS)
```

---

## ШАГ 1: Создание Telegram-бота (1 минута)

1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду: `/newbot`.
3. Укажите имя бота (например: `MIRRORS Finance Bot`).
4. Укажите username бота (должен заканчиваться на `bot`, например: `mirrors_fin_bot`).
5. Скопируйте полученный **HTTP API Token** (например: `7482910482:AAFlk...`). Он понадобится в Шаге 3.

---

## ШАГ 2: Создание Google Таблицы (1 минута)

1. Перейдите на [Google Sheets](https://sheets.new) и создайте новую таблицу.
2. Назовите её: **`MIRRORS_Finance`**.
3. В верхнем меню выберите: **Расширения** ➔ **Apps Script** (в новой вкладке откроется редактор кода).

---

## ШАГ 3: Установка скрипта Google Apps Script (2 минуты)

1. В открывшемся окне Apps Script сотрите весь стандартный текст `function myFunction() { ... }`.
2. Скопируйте и вставьте весь код из файла **`google_apps_script.js`** (находится в репозитории проекта).
3. В самом начале скрипта найдите строчку:
   ```javascript
   const BOT_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER";
   ```
   и замените её на токен, полученный в Шаге 1 от `@BotFather`.
4. (Опционально) Чтобы закрыть доступ посторонним, укажите свой Telegram ID в строке:
   ```javascript
   const ALLOWED_USER_IDS = [123456789]; // Узнать свой ID можно у @userinfobot
   ```
5. Нажмите иконку **💾 Сохранить** (Ctrl+S / Cmd+S).

---

## ШАГ 4: Развертывание Веб-приложения (Deploy) (1 минута)

1. В правом верхнем углу Apps Script нажмите синюю кнопку **Начать развертывание** (Deploy) ➔ **Новое развертывание** (New deployment).
2. Нажмите на шестеренку слева от «Выберите тип» и выберите **Веб-приложение** (Web app).
3. Заполните поля:
   * **Описание:** `MIRRORS Finance Webhook`
   * **Выполнять от имени:** `Меня (ваш email)`
   * **У кого есть доступ:** **`Все (Anyone)`** *(КРИТИЧНО! Иначе Telegram и дашборд не смогут присылать данные).*
4. Нажмите **Развернуть** (Deploy).
5. Google запросит доступ к вашей таблице — нажмите «Предоставить доступ», выберите свой аккаунт, нажмите *Advanced (Дополнительно)* ➔ *Перейти к проекту (небезопасно)* ➔ *Разрешить*.
6. Скопируйте полученный **URL веб-приложения** (заканчивается на `/exec`).

---

## ШАГ 5: Активация Вебхука Telegram (30 секунд)

1. В том же окне редактора Apps Script в самом низу кода найдите функцию `setTelegramWebhook()`:
   ```javascript
   function setTelegramWebhook() {
     const WEB_APP_URL = "ВСТАВЬТЕ_СЮДА_URL_ВЕБ_ПРИЛОЖЕНИЯ";
     ...
   ```
2. Вставьте туда ваш URL из Шага 4.
3. В верхней панели редактора выберите функцию **`setTelegramWebhook`** в выпадающем списке и нажмите **Выполнить (Run)**.
4. В журнале выполнения появится: `{"ok":true,"result":true,"description":"Webhook was set"}`.
   🎉 **Бот активирован и готов к работе!**

---

## ШАГ 6: Подключение к Дашборду на Vercel (1 минута)

1. Откройте ваш онлайн-дашборд на Vercel.
2. Перейдите на вкладку **💰 P&L & Чистая Прибыль**.
3. Нажмите кнопку **`☁️ Google Sheets`**.
4. Вставьте ваш **URL веб-приложения** (из Шага 4) и нажмите **🔄 Синхронизировать**.
5. Появится статус: **`🟢 Подключено`**. Теперь при внесении операций с телефона дашборд автоматически обновляет P&L и кассу!
